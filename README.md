# 리레벨 연구소

제공된 게임 데이터와 코드를 분석해 만든 비공식 정적 사이트입니다. 빌드 도구 없이 `index.html`을 브라우저에서 열 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 공개 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드하고 기본 브랜치에 커밋합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**로 설정합니다.
4. 브랜치는 기본 브랜치(보통 `main`), 폴더는 **/(root)** 를 선택하고 저장합니다.
5. Pages 화면에 게시 주소가 표시될 때까지 기다립니다. 주소는 대개 `https://사용자명.github.io/저장소명/`입니다.

Git을 사용하는 경우 이 폴더에서 새 저장소를 초기화하고 본인 저장소에 푸시해도 됩니다. Pages 설정은 위와 동일합니다.

정적 파일이므로 별도 서버, 패키지 설치, API 키가 필요하지 않습니다. APK와 네이티브 바이너리는 포함되어 있지 않습니다.
